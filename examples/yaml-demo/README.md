# サンプル: 古書店の閉店後(YAML の書き方の見本)

作者向け YAML(docs/yaml.md)の書き方の見本。キャラクターごとのタイムライン、「時:分」の時刻、ハンドアウトの時系列表を使っている。

- `scenario.yaml`: 作者が書く YAML
- `scenario.json`: `mmcheck convert scenario.yaml` の出力(正規化 JSON)。Go のテストで、YAML の変換結果と一致することを確かめる
- `expected.json`: `scenario.json` に対する Lean オラクルの出力

## 判定結果

意図して入れた不整合が2つ検出される。

| コード | 内容 |
|---|---|
| K008 | 客のハンドアウトの時系列表は「店に入ったのは 21:05 ごろ」だが、タイムラインでは 21:10 に入店している(許容誤差 2 分) |
| T003 | 店員はバックルームからカウンターへ 0 分で移動しているが、店内の移動には 1 分かかる |
