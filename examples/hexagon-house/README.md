# サンプル: オタサーの姫殺人事件〜六角館の殺人編〜

`the-hexagon-house-murders` のハンドアウト・エンディング・真相・カード(ルームデータ内の画像 28 枚)を、**仕様 0.5.1** の正規化 JSON で表したもの(0.3.0 で作成)。

- `scenario.json`: モデル化したシナリオ(イベント 90 件、証言 19 件、偽の知識 2 件、断言 4 件)
- `expected.json`: 仕様 0.5.1 の Lean オラクルの出力(Python の試作判定器の出力とも一致)。

**原作に忠実にモデル化している。** 記述のない行為は補っていない。例外は次の2点で、どちらも `note` に明記している。
- 移動時間は推定値
- 腕時計を自室の鞄に入れる行為(鞄から盗まれたという記述から推定)

## 判定結果

**error 4件、warning 2件。** 0.2.0 と同じで、どれも原作の2つの不整合から出ている。0.3.0 で加えた検査(証言 19 件、偽の知識 2 件、断言 4 件)は、すべて通った。

| 不整合 | 検出結果 |
|---|---|
| **リップクリーム**: ウシロカワダは「明日返そうとポケットにしまった」のに、探索カードでは「ウシロカワダの部屋」で見つかる | H006 error、K005 error、H003 warning |
| **睡眠薬**: シメジは睡眠薬を持ったままで、部屋に置く記述がないのに、探索カードでは「シメジの部屋」で見つかる | 同上(H006、K005、H003) |

検査を通った主な項目:
- **真相の断言**: 01:00 にカイチョウはヒメの部屋にいて自室にはいない。クロセはカイチョウの部屋にいる。シメジとウシロカワダは喫煙所にいる。どれもタイムラインと一致する。
- **証言**: 4人の時系列表とカードの時刻(0:50 の喫煙所、01:10 の廊下など、複数人が同じ出来事を証言するもの)は、タイムラインと 5 分以内で一致する。
- **偽の知識**: カイチョウの思い込みも、ヒメの嘘も、否定する知識がプレイヤーに手に入る。

**修正の確認**: 「シメジが 0:02 に睡眠薬を自室に置く」「ウシロカワダが 01:14 にリップクリームを自室に置く」の2イベントを加えると、検出結果は 0 件になる。

0.2.0 で試した M1〜M9(移動時間、エンディングの重複、遭遇、死亡後の行動、手がかりの消失など)に加えて、0.3.0 の規則を試した。

| H-M11 | シメジが喫煙所に来るのを 1:05 にする | **A001**: 断言「01:00 にシメジは喫煙所にいる」(アリバイ)が崩れる。**K008** × 3: シメジのカード「0:50 喫煙所でウシロカワダと会う」と、2人の時系列表の 0:50 がずれる |
| H-M12 | 山札「ヒメについて」とカイチョウの部屋のタバコのカードを消し、カイチョウがタバコを見た記述も消す | **K006**: カイチョウの「ヒメは完璧なアイドル」という思い込みを見破れない。K003 × 2: 真相の根拠が入手できない |

## 気づいた点

- 1つの不整合から H006、K005、H003 の3件が出る。どれも正しい指摘だが重複が多い。Go の表示層で関連する検出結果をまとめて表示するのがよさそう(仕様の出力は今のまま)。
- 投票の連動(「ストーカーを特定」⇔ 投票先)は `constraints` で手書きしている。ゴールに条件式を直接書けると、より自然に書ける。
