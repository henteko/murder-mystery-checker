# サンプル: 荒木コノミの真相

`riddory/docs/stories/araki-konomi-no-shinsou` のハンドアウト・エンディング・真相・カード(ルームデータ内 23 枚)を、**仕様 0.3.1** の正規化 JSON で表したもの(0.3.0 で作成。0.3.1 の変更は出力に影響しない)。

- `scenario.json`: モデル化したシナリオ(イベント 29 件、証言 10 件、偽の知識 3 件、断言 3 件)
- `expected.json`: 仕様 0.3.0 の試作判定器(Python、使い捨て)による出力。Lean オラクルの出力ではないので、Phase 3 でオラクルの出力に置き換える。

## モデル化の方針

「解説/真相」の時系列を**客観的なタイムライン**とし、各ハンドアウトの記述は**知識**として載せた。0.3.0 では、知識に真偽と時刻を持たせられる。

| 原作 | 仕様 0.3.0 での表現 |
|---|---|
| ソウスケの「付き合っていた」「練習に付き合った」「屋上に付き合った」 | **偽の知識**(`truth: false`)。それぞれを否定する真の知識を `contradicted_by` に指定した(例: 「付き合っていた」← 「コノミは恋愛より部活に集中したい」「コノミはツムギの恋心を知っていた」) |
| ソウスケが物陰からコノミを見ていた(真相) | 物陰から教室を観察する `observe`。物陰から教室が見えることは `perception` で宣言 |
| トムが教室の前を通りかかる、部室の窓から遺体を見る・悲鳴を聞く、ソウスケが屋上から下を見る | `perception` と `observe.target_location`(離れた場所の観察) |
| コノミの落下と即死 | `move`(`mode: "fall"`, `fatal: true`)。0.2.0 の「0分の travel」と「1分後の die」による代用をやめた |
| 証拠カードと時系列表の時刻 | **証言**(`about` + `claimed_at`)。許容誤差は 5 分(`claim_tolerance`) |
| 「18:00 には全員アリバイがある」「17:59 コノミは屋上」「トムが見たのはコノミ1人」 | **断言**(`assertions`) |
| 探索カード「〇〇について」「〇〇の心の声」 | `clues[].deck`(山札) |
| エンディング1〜4(最多得票 / その他または同数) | `plurality` と `tie` |
| 移動時間、物陰とソウスケの初期位置 | **推定** |

## 判定結果

**error 2件。** どちらも証言の時刻のずれ(K008)で、0.2.0 では手作業でしか見つけられなかった不整合を、判定器が検出した。

| コード | 内容 |
|---|---|
| **K008** | `f_tom_table_1810`: トムの時系列表は悲鳴を聞いた時刻を **18:10** とするが、実際の観察は 18:01。証拠カード(18:00)とツムギの発見(18:00)とも合わない |
| **K008** | `f_s_table_1750_vending`: ソウスケの時系列表は自販機に向かった時刻を **17:50** の行に書くが、証拠カードと、タイムライン上の移動は 18:00 |

検査を通った主な項目:
- ソウスケの3つの思い込みは、どれも否定する知識がプレイヤーに手に入る(K006 なし)。
- 真相が依存する知識はすべて真で、入手可能(K003、K007 なし)。
- 断言「18:00 に屋上には PC が誰もいない」は成り立つ。ただし**境界ぎりぎり**: ソウスケは 18:00 に屋上を出発しているので、18:00 ちょうどには移動中とみなされる。出発が1分でも遅れると成り立たない(M2)。
- エンディングは、投票 4³ = 64 通りのどの場合もちょうど1つに決まる。

**修正の確認**: 2つの時系列表の時刻を証拠カードに合わせて 18:00 にすると、検出結果は 0 件になる(F1)。

## 残る課題

- 「ソウスケのみ『事件』と言っている」という言葉づかいの手がかりは、対象外(知識の中身や文面は解釈しない)。
- 「一緒にいたという目撃情報がない」という、証拠がないこと自体を根拠にする推理は、断言(absent)で近似した。
